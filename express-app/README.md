# Refresh Token Authentication — ExpressJS Implementation

This Express application demonstrates production-ready refresh token authentication with rotation, hashed storage, multi-device sessions, logout and revoke-all flows.

See top-level documentation for full theory, diagrams, and the companion NestJS implementation.

Quick start

1. copy `.env.example` to `.env`
2. npm install
3. npx prisma generate
4. npx prisma db push
5. npm run dev
